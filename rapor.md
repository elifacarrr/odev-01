# ÖDEV 1 - GENEL DEĞERLENDİRME RAPORU
Elif Betül Acar  
Veritabanı ve Python Temelleri  

Bu ödev kapsamında; Python dili ile veri analizi ve döngü yapıları kurulmuş, ilişkisel veritabanı mimarisinin temel kavramları incelenmiştir. SQL dilinde `SELECT`, `WHERE`, `GROUP BY` komutları ve `NULL` veri analizleri pratik edilmiştir. Süreç boyunca sürüm kontrolü için GitHub kullanılmış ve dosyalar başarıyla repoya aktarılmıştır.
